# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data to identify the factors that influence customer retention and understand patterns leading to customer churn.

## Objective
- Analyze customer churn trends
- Identify key factors affecting customer retention
- Understand customer demographics and subscription behavior
- Generate insights to improve customer retention strategies

## Tools Used
- Power BI
- Excel

## Analysis Performed
- Data cleaning and preprocessing
- Churn rate analysis
- Customer demographic analysis
- Contract and payment method analysis
- Data visualization using Power BI

## Dashboard Highlights
The dashboard includes:
- Total Customers
- Churned Customers
- Churn Rate
- Gender-wise Customer Distribution
- Churn by Contract Type
- Churn by Payment Method
- Internet Service Analysis

## Key Insights
The analysis identifies customer groups with higher churn rates and highlights factors influencing customer retention, helping businesses make informed decisions to improve customer loyalty.
