# Business Sales Analysis

## Project Overview
This project focuses on analyzing business sales data to identify revenue trends, top-selling products, high-value categories, and regional performance.

## Objective
- Analyze sales performance
- Identify top-performing products and categories
- Understand regional sales trends
- Generate business insights using data visualization

## Tools Used
- Power BI
- Python
- Excel

## Analysis Performed
- Data cleaning and preprocessing
- Sales trend analysis
- Category-wise sales analysis
- Regional performance analysis
- KPI development

## Dashboard Highlights
The Power BI dashboard includes:
- Total Sales
- Total Orders
- Total Customers
- Average Sales
- Sales by Category
- Regional Sales Performance
- Sales Trends

## Key Insights
The analysis helps identify important business patterns and supports data-driven decision making.
